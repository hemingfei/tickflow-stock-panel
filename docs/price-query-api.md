# 股价查询 API（供 vpush 调用）— 本项目实现契约

> 基于 vpush 侧原始设计文档 `vpush/docs/price-query-api.md`（v1）适配本仓库架构。
> 语义（时刻价规则、错误模型、批量行为）与原文档一致；本文档记录落地到
> tickflow-stock-panel 的具体边界：价格口径、代码格式、鉴权与数据源约束。
> 实现与本文档不一致时以实现代码 + 本文档共同复核后修正。

## 1. 功能定位

把大V公开发言中的操作事件（建仓/加仓/减仓/清仓）锚定到股价：事件时刻价作
预估成本/卖价，最新价算浮动盈亏。

- 只查 A 股个股（沪深）。北交所（`bj` 前缀）按 `unknown_code` 返回，不报错。
- **历史时刻价不可变**：同一 (code, at) 任何时间查询结果相同，调用方可无限期缓存。
- 最新价随行情变化：调用方自带 5 分钟 TTL 本地缓存。
- 量级：单次页面打开触发一次批量（≤50 item），日均千 item 级。

## 2. 时刻价规则（与原文档 §2.1 一条规则不变）

**返回「不超过 at 时刻」的最近一个有效成交价格，并返回该价格实际形成的时刻
actual_at。不使用任何 at 之后的价格（无未来信息）。**

| at 落点 | price 取值 | kind |
|---|---|---|
| 连续竞价 09:30-11:30 / 13:00-15:00 | at 分钟或之前最后一笔成交 | trade |
| 开盘集合竞价 09:15-09:25 | 前一交易日收盘价（当日尚无成交） | close |
| 09:25-09:30 | 当日开盘价（09:25 撮合产生） | auction |
| 午间休市 11:30-13:00 | 当日上午最后一笔成交 | trade |
| 收盘后 15:00 之后 | 当日收盘价 | close |
| 非交易日（周末/节假日） | 之前最近交易日的收盘价 | close |
| at 当日停牌 | 停牌前最近有效价格（可能跨交易日） | 同上 |

停牌（含长期停牌）**不报错**：best-effort 返回最近有效价 + 如实的 actual_at。

## 3. 价格口径（本项目适配点，关键）

历史价格统一使用**不复权原始价**：

- 日线来源 `kline_daily`（本地 parquet，不复权 OHLCV）。
- 分钟K落盘为 SDK 端前复权（qfq），服务在读取后**按除权因子还原为不复权价**
  再参与时刻价计算（当日无除权事件时因子为 1，价格即原值）。
- 不复权是「(code, at) 永久不变」的前提：前复权价随未来除权整体漂移，
  会破坏历史查询的幂等性。vpush 盈亏计算以原始价为锚（大V发言报价即原始价），
  复权口径由调用方按需处理。

## 4. 接口定义

### 4.1 单笔查询

`GET /api/v1/price?code=sh600519&at=2026-09-01T09:16:00`

参数：

- `code` 必填。交易所前缀 + 6 位数字：`sh` / `sz`（`bj` 无本地数据，返回 404）
- `at` 可选。北京时间 `YYYY-MM-DDTHH:MM:SS`（naive，服务端按北京时间解释）。
  **省略 = 查最新价**。

响应 `200`：

```json
{
  "code": "sh600519",
  "name": "贵州茅台",
  "at": "2026-09-01T09:16:00",
  "price": 1450.00,
  "actual_at": "2026-08-31T15:00:00",
  "kind": "close"
}
```

字段：

- `price`：float，A 股两位小数
- `actual_at`：price 实际形成时刻（取前收则为前收日 15:00:00；分钟成交为该分钟
  K 线标注时刻；最新价为最后成交/收盘时刻）
- `kind`：`trade` / `close` / `auction`
- `name`：证券简称（本仓库 instruments 维表）

### 4.2 批量查询

`POST /api/v1/prices`，请求体：

```json
{
  "items": [
    {"code": "sh600519", "at": "2026-09-01T09:16:00"},
    {"code": "sz300750"},
    {"code": "sh999999"}
  ]
}
```

- 单次 ≤ 50 item，超出整单 400；items 空也 400
- item 内 `at` 可省略（该 item 查最新价）；同一 (code, at) 允许重复
- **逐 item 独立成败**：整体 HTTP 200，失败在 item 内表达
- 响应 items 顺序与请求一一对齐
- 同一请求内的重复 (code, at) 在服务内合并查询，不重复读盘

响应 `200`：

```json
{
  "items": [
    {"code": "sh600519", "at": "2026-09-01T09:16:00", "status": "ok",
     "name": "贵州茅台", "price": 1450.00, "actual_at": "2026-08-31T15:00:00", "kind": "close"},
    {"code": "sz300750", "status": "ok", "name": "宁德时代",
     "price": 188.55, "actual_at": "2026-09-18T10:47:00", "kind": "trade"},
    {"code": "sh999999", "status": "error", "error": "unknown_code"}
  ]
}
```

## 5. 鉴权（本项目适配点）

`Authorization: Bearer <token>`，无 Cookie 依赖（vpush 服务端调用，无浏览器）。

- token 由本仓库 `secrets_store` 持久化（`data/user_data/secrets.json`，字段
  `vpush_api_token`），服务器主人在设置接口生成/轮换。
- 未配置 token 时端点对所有请求返回 401（fail-closed，不提供匿名试用）。
- `/api/v1/*` 加入认证中间件白名单（跳过面板会话检查），由路由自身校验 Bearer。

## 6. 错误模型

HTTP 层（整单失败）：

- 400：code 非法（前缀/位数）/ at 格式错 / items 超 50 或空
- 401：Bearer token 缺失或错误
- 404：`bj` 前缀（本项目无北交所数据）——单笔端点行为
- 5xx：内部错误

item 层（批量内单项失败，`status: "error"`）：

- `unknown_code`：代码不存在于 instruments 维表，或前缀不支持（bj）
- `no_data`：at 早于本地任何可得价格（如上市前、本地数据起点之前）
  或该代码无本地日线数据

## 7. 数据源与实现边界（本项目适配点）

- 历史查询只读本地 `KlineRepository`（`kline_daily` 日K + `kline_minute` 分钟K
  parquet），**不触发上游数据源实时拉取**：外部调用不应隐式引发 TickFlow 请求
  或同步任务（插件化与 fail-closed 原则）。
- 本地无分钟K的交易日，盘中时刻降级为「最近日线边界」：at < 15:00 且当日有日K
  时按当日开盘价（9:25 后）或前收（9:25 前）近似，`kind` 如实标注
  （`auction` / `close`），actual_at 标注对应形成时刻。降级路径在文档如此声明，
  不静默伪装成分钟精度。
- 最新价（at 省略）优先读实时行情 enriched 缓存（quote_service 落盘的当日行），
  无当日实时数据时回退本地最近日K收盘价。
- 交易日/停牌判定不依赖外部日历：直接取「at 之前最近一根有成交的日K」，
  跨节假日/停牌天然向前回溯。`filter_halt_days` 同款停牌判据（open=high=0 或
  量额双零）过滤停牌日，避免取到数据源填充的前收假行。

## 8. 非功能约定

- 时间口径：一律北京时间，格式 `YYYY-MM-DDTHH:MM:SS`
- 幂等/可缓存：GET 幂等；(code, at) 历史查询结果永久不变（不复权口径保证），
  可被任意中间层透明缓存；仅「最新价」（无 at）会变
- 延迟：历史查询走本地 parquet，P95 < 1s；最新价允许 ≤ 1 分钟延迟
  （受实时行情轮询间隔约束）
- 数据覆盖：沪深 A 股全量，覆盖范围为本地已同步历史（默认近 2 年+，取决于用户
  数据源档位与同步配置）

## 9. 调用方接入示例（联调参考）

打开大V盈亏页 → 收集其 30-90 天窗口内全部事件 (code, occurred_at) + 在持股
最新价 → 去重 → 1 次 POST /api/v1/prices → 历史项写本地永久缓存，最新价项
TTL 300s。
